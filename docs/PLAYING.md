# 游玩指南

[在线开玩](https://ranko-sama.github.io/ruanpapa/) · [返回首页](../README.md)

## 选一场派对

选择角色，在「对局设置」里选择模式与舞台，再点击「开始乱斗」。单人局由机器人补足其余席位，经典乱斗共有六个角色参战。

| 模式 | 获胜方式 |
| --- | --- |
| 经典乱斗 | 把对手打出擂台，先完成 7 次击飞 |
| 合作闯关 | 单人或双人组队，在限时内连续挑战五座舞台 |
| 护旗大战 | 夺走敌旗并带回己方旗座，先夺 3 旗；己方旗帜须在旗座上 |
| 区域争夺 | 独占中央区域，先累计占领 20 秒 |
| 推车派对 | 靠近糖果车，把它护送到对手一侧终点 |
| 软糖国王 | 拾取并持有王冠，先累计戴满 20 秒；重击会震掉王冠 |

## 两台设备一起玩

在线版支持两名真人通过 WebRTC 直连，其余席位由机器人补足。

1. 房主打开「好友联机」，点击「创建房间」。
2. 房主复制邀请链接，发给朋友。朋友打开链接，点击加入并生成回执码。
3. 朋友把回执码交回房主，房主将它粘贴到回执输入框，完成连接。
4. 双方显示「好友已入场」后，选好各自的战士，由房主点击「开始乱斗」。

连接需要双方网络支持 WebRTC 直连。当前在线版使用 STUN 辅助配对，未配置 TURN 中继服务。

同屏游玩时，在「对局设置」中选择「本地双人」并指定 2P 角色即可，两名玩家共用同一台设备与镜头。

## 操作

| 动作 | 1P / 联机玩家 | 同屏 2P |
| --- | --- | --- |
| 移动 | `W A S D` | 方向键 |
| 普通攻击 | `J` 或鼠标左键 | `,` 或小键盘 `1` |
| 角色技能 | `K` 或鼠标右键 | `.` 或小键盘 `2` |
| 跳跃 | `空格` | `Enter` 或小键盘 `0` |
| 表情 | `L` | `/` 或小键盘 `3` |
| 切换视角 | `V` | 共用镜头 |
| 转动第三人称镜头 | 鼠标或 `Q / E` | 镜头跟随 1P |
| 暂停 | `Esc` | `Esc` |

单人也可以用方向键。触屏设备提供屏幕摇杆和动作按钮。

每局默认使用右肩越肩视角，人物位于画面左下方。按 `V` 依次切换至居中正后方、全场视角，再回到越肩。点击擂台后可以用鼠标环视，`W` 朝镜头前方移动，攻击朝向中央准星。触屏可滑动擂台空白处转向，点击右上角镜头按钮切换视角。联机双方各自控制自己的镜头，回放时也能切换。

## 场地也会捣乱

- **云顶弹弹台**：宽阔的充气擂台，中央旋转软杆可以被技能加速。
- **汽水工厂**：摩擦更低，冲出去之前要留出刹车距离。
- **轨道乐园**：较低的重力与反向转杆，让抛物线变得更夸张。
- **潮汐船坞**：三座桥连接两岸，中央宽桥承载推车路线；反向传送带会运送角色和箱子。
- **霓虹弹珠台**：五根弹簧柱改变碰撞方向，从上方落下会被弹高；小心前端的 V 形落口。

黄黑框中的玻璃平时可以正常通行。重落地或范围技能会触发裂纹，预警 1.35 秒后破碎，4 秒后修复。对局还会随机出现失重、侧风和弹跳事件。

## 收藏与精彩回放

完成三场对局或通关合作闯关第三关可解锁闪电兔兔。皮肤、配饰、表情和成就的条件可以在「我的收藏」查看。

结算时自动播放精彩瞬间，最近三场的片段与成长进度保存在当前浏览器。更换设备或清除浏览器数据后，不会自动同步这些记录。
